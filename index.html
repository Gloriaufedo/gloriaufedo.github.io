HOW I WORK

The analysis matters as much as the chart.

A small example of the SQL layer behind my analytical work.

SQL · analytical transformation PostgreSQL 
SELECT
    customer_state,
    COUNT(DISTINCT customer_id) AS new_customers,
    COUNT(DISTINCT CASE
        WHEN first_order_date <= signup_date + INTERVAL '30 days'
        THEN customer_id
    END) AS customers_converted
FROM customer_activity
WHERE signup_year = 2024
GROUP BY customer_state
ORDER BY new_customers DESC;

The point is not the query alone. I use the SQL layer to define the metric before it reaches the dashboard.
